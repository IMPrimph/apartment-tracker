Design Decisions

  • Collapsed by default — you rarely need this. One click to expand.
  • Grouped by month — natural time-based grouping instead of by type (since Dashboard already shows type totals).
  • Filter chips — quick type filtering when expanded. "All" selected by default.
  • No inline Edit/Delete buttons — tap a row to open edit mode (reuses the quick-add form with pre-filled values + delete option). Keeps rows clean.
  • Color-coded dots — blue (bank loan), green (cash), amber (EMI), purple (misc). Quick visual scan.
  • Export lives here — moved from the header. It's a history-related action, not a primary one.
  • Auto-generated labels — "Bank Loan", "EMI Payment", "Cash Payment" based on type. No user-entered description needed.
