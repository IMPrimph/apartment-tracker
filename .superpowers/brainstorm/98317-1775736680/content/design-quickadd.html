Key Behaviors

  • Type chips — tap to select. No dropdown. EMI defaults as selected since it's your most common entry.
  • EMI pre-fill — when EMI is selected, the amount auto-fills with your last EMI amount. Just hit Save if it's the same. Change the number if it's different.
  • Amount-to-words — shown below the input as a sanity check (existing feature, kept).
  • Auto date — always today. No date picker. If you need to backdate, a small "change date" link appears on hover/tap.
  • No description field — removed as discussed. Auto-generated label stored internally (e.g., "EMI Payment", "Bank Loan Payment").
  • Keyboard shortcut — Cmd+K focuses the amount input directly.
  • On save — dashboard numbers update immediately. A subtle confirmation toast appears briefly.
